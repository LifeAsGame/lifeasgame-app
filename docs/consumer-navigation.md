# 소비자 화면의 탐색·표시 계약

- 플레이어 요약은 workspace 밖, 주 메뉴 왼쪽에 표시한다. 1200px 미만에서는 ‘플레이어 요약’ 버튼으로 별도 단계에 접근한다. 부모 플레이어 패널은 성장 진입으로 축소하지 않는다.
- 성장 → 경험치 이력 → 변동 상세는 명시적으로 선택해 연다. 뒤로 가기는 역순으로 진행하며 호출자에 포커스를 돌려준다. 성장 조회의 `exp`와 확정 변동 값만 표시한다. 현재 레벨 경험치의 분모·남은 경험치·백분율은 별도 읽기 계약이 생기기 전까지 계산하지 않는다.
- 목록/상세의 역할은 `PanelStage.panelRole`과 `side`로 표시한다. 데스크톱 여정은 상세 왼쪽, 메뉴 중앙, 목록 오른쪽을 유지한다. 메뉴와 상세는 전환 중에도 같은 축 좌표를 사용한다. 이 조회 배치는 이후 편집 패널 배치 규칙과 별개다.
- 뒤로 가기는 `data-panel-back` 동작으로 식별한다. 표시 언어로 동작을 찾지 않는다. 비활성·종료 중 단계는 제외하고 가장 깊은 활성 단계의 기존 콜백을 호출한다. 확인창의 Escape는 확인창만 취소하며 입력과 호출자 포커스를 유지한다.
- 메뉴를 닫고 Home으로 돌아오면 `/api/v1/home`을 GET으로 다시 조회한다. 기존 요약은 조회 중과 실패 후에도 남는다. 다시 조회는 GET만 실행하고 저장·수락·보상 명령을 재전송하지 않는다. 이전 Home 방문의 늦은 응답은 새 방문을 덮어쓰지 않는다.

## 한국어 표시 범위

주 메뉴·하위 메뉴, 공통 뒤로 가기·확인창·선택 안내, 플레이어 요약, 성장, 여정의 목록·상세·보상 정산, Home 요약의 기본 문구를 한국어로 표시한다. API enum·ID·코드·서버에서 받은 제목과 설명은 변경하지 않는다. 알려진 상태 값은 표시용 매핑을 적용하며, 알 수 없는 값은 원문을 유지한다. 브랜드·단위·능력치 약어는 보조 표기로 남는다.

아래는 후속 도메인 작업에서 이어갈 영어 표시 범위다. 전체 화면 번역 완료를 의미하지 않는다.

| 도메인 | 남은 사용자 표기 예 | 담당 파일 |
|---|---|---|
| 업적·자격증·칭호·취미 | 목록/상세 제목, 등록·수정·삭제, 로딩·오류·확인 | `features/player/{Achievement,Certification,Title,Hobby}Shell.tsx`, `forms.ts` |
| Journal·Quick Record·Collection | 기록 필드, 타입·필터, 저장/재시도/삭제 확인, 상세·복귀 이름 | `features/lifelog/{Journal,Collection}Shell.tsx` |
| Exercise·Media | 입력·분류·상태, 조회·수정·삭제 동작 | `features/lifelog/{Exercise,Media}Shell.tsx` |
| 소지품·장비·수신함 | Gear Parts, 슬롯·후보, 아이템 설명 조회·수령 동작 | `features/inventory/*Shell.tsx`, `shared/ui/ItemDescription.tsx` |
| 거래소 | 지갑·상점·거래의 내부 필드, 주문·오류 문구 | `features/market/ExchangeShell.tsx` |
| 역할 일정·공유 모임 | 일정 조회 내부 문구, 공유 모임 연결 | `features/role/RoleShell.tsx`, `features/social/*` |
| 계정·설정·알림 | 로그인·가입·온보딩, 설정 옵션, 알림 상태 | `features/auth/*`, `features/system/settings/*`, `features/notification/*` |

각 후속 작업은 기존 필수값·소유권·확정 상태·멱등성 계약을 유지해야 한다. 공유 모임과 경험치 읽기 응답 확장은 별도 작업으로 유지한다.

## 인물 · 역할 관리

- 역할 선택 전에 인물·역할을 고른다. 인물 목록·초안·선택은 역할과 독립적이며 역할이 없어도 접근할 수 있다.
- 메뉴를 왼쪽으로 80px 이상 끌면 목록 자리에 등록/연결 폼을 연다. 항목 드래그는 수정·보관 선택지만 열며 명령을 실행하지 않는다. 세로 스크롤은 유지하며 추가·작업 버튼으로 같은 동작에 접근할 수 있다.
- 수정은 목록을 유지한 우측 패널에서 진행한다. 취소·Escape는 목록의 선택·스크롤·호출자 포커스를 복원한다. 이전 인물/역할의 늦은 응답은 새 선택을 변경하지 않는다.
- 인물·역할·해당 역할의 관계 보관을 구분해 확인한다. 관계 보관은 인물과 다른 역할의 관계를 보존한다. 보관 인물의 기존 관계를 유지하고 상태를 표시하며, 신규 연결은 서버가 확인한 사용 중인 인물로 제한한다.
- 관계 응답에 인물 상태가 없으면 기존 소유 인물 상세 조회를 사용한다. 조회 실패는 상태 미확인으로 표시한다. 복원·친밀도 라벨·최근 대화 저장·나이 필드는 후속 정책/계약으로 유지한다.
